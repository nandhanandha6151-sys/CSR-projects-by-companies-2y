# 📊 Corporate Social Responsibility (CSR) Analysis | Data Analytics Project

## 📌 Project Overview

This project analyzes **Corporate Social Responsibility (CSR)** spending of companies across India to identify trends, funding patterns, sector-wise investments, state-wise distribution, and project outcomes. The analysis helps understand how companies allocate and utilize CSR funds while uncovering meaningful business insights through data analysis and visualization.

This project demonstrates the complete Data Analytics workflow—from raw data cleaning to exploratory data analysis (EDA), visualization, and dashboard creation.

---

## 🎯 Project Objectives

* Analyze CSR spending across different industries and sectors.
* Compare allocated budgets with actual expenditure.
* Identify top contributing companies and states.
* Analyze CSR investment trends over multiple years.
* Discover sector-wise CSR funding patterns.
* Generate actionable insights through data visualization.

---

## 📂 Dataset

The dataset contains information related to Corporate Social Responsibility activities, including:

* Company Name
* Company Category
* State
* CSR Sector
* Financial Year
* Project Outlay
* Amount Spent
* Project Details
* CSR Activities

## 📊 Key Insights

* Companies allocated significantly higher CSR budgets than the actual amount spent.
* Education and Healthcare received the highest CSR investments.
* A few states accounted for the majority of CSR expenditure.
* Large companies contributed the largest share of CSR spending.
* CSR investments showed noticeable growth over recent financial years.
* Certain sectors consistently attracted higher funding due to national development priorities.
